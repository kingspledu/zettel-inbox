Firebase 연결 필요

Firebase에는 텍스트와 메타데이터, 비공개 GitHub에는 첨부 원본을 저장합니다. 최초 설정 안내

Firebase 규칙이 설정되어 있어야 연결됩니다. Firebase 로그인은 이 브라우저에 유지되며 다음 방문부터 자동 연결됩니다. 로그아웃하면 자동 연결을 중지합니다. GitHub 토큰은 첨부파일 사용 시 별도로 입력하며 저장하지 않습니다.

텍스트·JSON 파일은 원문을 함께 보관합니다. 그 외 파일은 첨부 원본으로 보관하며 텍스트를 추출하지 않습니다.

Gemini가 읽을 자료 페이지

선택한 자료의 고정 사본을 공개 웹페이지와 공개 GitHub 저장소에 게시합니다. 누구나 읽을 수 있으며 링크를 아는 사람만 볼 수 있도록 제한되지 않습니다. 게시 후 Git 이력에도 남습니다.

기본 포함: 선택한 자료의 제목·ID·본문·출처·태그와 운영 지침. 비포함: 로그인 정보·토큰·첨부 원본·선택하지 않은 자료.

이미지·PDF 등 원본은 공개하지 않습니다. 외부 링크 내용도 자동으로 읽거나 포함하지 않습니다.

첨부 전용 토큰과 별개입니다. 토큰 만들기 · 현재 탭에서만 사용하며 저장하지 않습니다.

Gemini가 실제로 읽은 자료 ID와 끝 표식을 확인한 후 같은 채팅에서 음성대화를 시작하세요. 페이지를 게시해도 Gemini의 전체 읽기나 음성대화 중 문맥 유지를 보장하지 않습니다. 공개 자료 수정·비공개 인박스 저장은 Gemini가 직접 할 수 없습니다.
