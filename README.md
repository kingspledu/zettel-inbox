# 모음 — 제텔카스텐 인박스

텍스트·링크·파일을 원문 그대로 수집하고 LLM 전달용 JSON으로 내보내는 웹앱입니다. GitHub Pages에서 실행합니다. Firebase + 비공개 GitHub를 사용합니다. **전용 프로젝트 moeum-inbox-kingspledu-2026이 기본 설정되어 있습니다. Google 로그인 후 저장할 수 있습니다. 브라우저 대체 저장은 하지 않습니다.** [클라우드 연결 안내](CLOUD_SETUP.md)를 참고하세요.

## 사용

**선택 자료 → Gemini 읽기 페이지**: 자료를 체크하고 미리보기 후 공개 동의와 게시용 GitHub 토큰을 입력합니다. 토큰은 공개 앱 저장소 `zettel-inbox` 하나의 Contents 읽기·쓰기 권한이 필요하며 기기에 저장하지 않습니다. 비공개 첨부 저장소 토큰과 별개입니다. 게시하면 `shares/<공유 ID>/`에 자바스크립트 없이 읽을 수 있는 고정 HTML이 추가되고 Pages에 자동 배포됩니다. 게시 확인 후 요청문을 Gemini 채팅에 붙여 넣고 실제 읽은 ID와 끝 표식을 확인하세요. 원문은 자동 요약하거나 분리하지 않습니다.

공개 범위는 제목·ID·본문·출처·태그·운영 지침입니다. 텍스트 첨부의 파일명·내용은 별도 선택 시에만 포함합니다. 이미지·PDF 원본과 외부 URL의 내용, 로그인·토큰, 선택하지 않은 자료는 포함하지 않습니다. 공개 사본은 인박스와 동기화되지 않습니다. 누구나 접근 가능하며 Git 이력에 남습니다. `noindex`는 접근 통제가 아닙니다. 게시를 중단하려면 해당 `shares/<공유 ID>/` 경로를 GitHub에서 삭제하고 다시 배포해야 하며 기존 복사본·캐시·Git 이력까지 지우지는 못합니다. 이 기능은 Gemini의 읽기 성공이나 음성대화 문맥 유지를 보장하지 않고, Gemini에 인박스 수정 권한을 부여하지 않습니다. 개인 자료를 게시하지 않은 상태에서 코드와 모의 API 동작을 검증합니다.

**인박스 추가용 프롬프트만 ↓** 버튼은 수집 자료·첨부·개인정보를 제외하고 명령 대기, 원문 보존, 최소 단위 분리, 업무지시 추가 규칙과 빈 인박스만 담은 JSON을 내려받습니다. 자료가 없어도 로그인 없이 사용할 수 있으며 기존 인박스는 변경하지 않습니다.

내용, 출처 또는 파일을 입력하고 저장합니다. 검색과 선택 후 전체 또는 선택 JSON을 다운로드합니다. 내보낸 JSON에는 원문과 base64 첨부, 텍스트 파일의 UTF-8 해석본, LLM 명령 대기 지침과 최소 의미 단위 분리 절차가 포함됩니다. JSON 가져오기는 이 앱의 백업만 지원하고 같은 ID는 건너뜁니다. 일반 JSON은 파일 첨부로 수집하세요.

## 저장과 제한

기본 저장소는 Firebase입니다. IndexedDB는 기존 자료의 명시적 이전에만 읽기 전용으로 사용하며 새 자료를 저장하지 않습니다. 연결하면 Firebase에 텍스트와 메타데이터를, 별도 비공개 GitHub에 첨부 원본을 저장합니다. LLM API 호출, 자동 분류, OCR, 음성 처리는 없습니다. LLM 음성대화는 다운로드한 JSON을 별도 서비스에 전달하여 수행합니다. PDF·이미지·오디오 등은 첨부 원본만 보관합니다. 텍스트 파일은 UTF-8을 가정합니다. 한 번의 첨부 합계는 25MB, 클라우드 DB 본문은 약 800KB로 제한합니다. JSON 백업이 필요합니다. JSON에는 첨부 원본까지 포함되므로 파일이 커질 수 있고 LLM의 업로드 한도와 형식 지원 여부를 확인해야 합니다. JSON 지침은 LLM의 준수를 보장하지 않습니다.

앱 코드는 공개 저장소와 Pages에 게시됩니다. 클라우드 첨부는 별도 비공개 저장소에 올라갑니다. Firebase 로그인은 브라우저에 유지해 다음 방문 시 자동 연결합니다. GitHub 토큰은 탭 메모리에만 유지하고 첨부파일 사용 시 입력합니다. 클라우드 삭제는 DB 항목만 삭제하며 GitHub 원본과 과거 이력은 남습니다. 공개 코드에 민감 자료를 직접 추가하지 마세요.

## 개발

별도 빌드는 없습니다. 클라우드 연결 시 Firebase SDK를 Google CDN에서 불러옵니다. `python -m http.server 8000`으로 실행하고 http://localhost:8000 에 접속합니다. `node test.cjs`와 `node cloud.test.cjs`로 내보내기·복원과 모의 API 기반 저장 분리를 검증합니다. 실제 Firebase 접근 규칙과 계정 연결은 별도로 검증해야 합니다. main 브랜치 push 시 GitHub Actions가 Pages에 배포합니다.

## 운영 프로젝트

moeum-inbox-kingspledu-2026 · Firestore 기본 DB, 서울(asia-northeast3). 결제 계정은 연결하지 않았습니다. firebase-config.js는 공개 웹 설정만 포함하며 관리자 인증정보는 포함하지 않습니다. 실제 서버 규칙은 운영자 Google 계정의 검증된 이메일과 사용자별 경로를 제한합니다. 저장소의 firestore.rules는 재사용용 잠금 템플릿입니다. 그대로 재배포하면 접근이 차단되므로 기존 운영 규칙을 확인하세요.
