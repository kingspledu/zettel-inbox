Instagram에서 공유한 링크

공개 페이지의 본문·댓글과 답글·이미지 주소·릴스 커버를 추출 시도합니다. 접근하지 못한 항목은 미수집으로 남습니다. 링크 보관 후 일괄 다운로드로 이미지 파일을 저장할 수 있습니다.
Instagram 공유로 수집하는 방법
갤럭시 Chrome에서 이 사이트를 열고 ‘앱 설치’를 선택하세요. 설치 후 Instagram 게시물·릴스의 공유 → 더 보기(다른 앱으로 공유) → ‘모음’을 선택하면 됩니다. 공유 앱 목록에 표시되는 시점과 방식은 기기·브라우저·Instagram 버전에 따라 다릅니다.
단순 바로가기 대신 앱으로 설치해야 합니다. iPhone에서는 이 공유 수신 방식을 지원하지 않을 수 있습니다.
새 자료 수집 · JSON 전용
Gemini에서 정리한 아이디어를 원문과 함께 등록
① 상단 지침 파일을 Gemini에 전달 → ② 음성대화 → ③ “지침대로 JSON으로 만들어줘” → ④ 파일 검증 후 등록
직접 텍스트·파일 첨부 등록은 지원하지 않습니다. 필수 필드·원문 범위·누락을 검증하며 기존 자료는 덮어쓰지 않습니다.


나의 인박스 


다운로드한 JSON에는 원문, 첨부파일, 최소 단위 분리 절차, 명령 대기 지침이 포함됩니다.
JSON 백업을 유지하세요. 클라우드 삭제는 DB 항목만 삭제하며 GitHub 첨부는 남습니다.
지침의 준수 여부는 사용하는 LLM에 따라 달라질 수 있습니다.


Instagram 웹 재수집
기존 자료는 수정하지 않습니다. 일괄 수집은 한 항목씩 조회하고 자동으로 새 항목에 보관합니다. 개별 재수집은 확인 후 저장합니다. PC 수집 도우미가 확인된 이미지와 릴스 커버를 받아 비공개 GitHub에 저장합니다. 토큰 입력은 필요 없습니다. PC에서 START-COLLECTOR.cmd를 실행해주세요. 제공되지 않는 이미지는 부분 수집으로 남습니다.
Gemini가 읽을 자료 페이지
선택한 자료의 고정 사본을 공개 웹페이지와 공개 GitHub 저장소에 게시합니다. 누구나 읽을 수 있으며 링크를 아는 사람만 볼 수 있도록 제한되지 않습니다. 게시 후 Git 이력에도 남습니다.
기본 포함: 선택한 자료의 제목·ID·본문·출처·태그와 운영 지침. 비포함: 로그인 정보·토큰·첨부 원본·선택하지 않은 자료.
이미지·PDF 등 원본은 공개하지 않습니다. 외부 링크 내용도 자동으로 읽거나 포함하지 않습니다.
첨부 전용 토큰과 별개입니다. 토큰 만들기 · 현재 탭에서만 사용하며 저장하지 않습니다.
Gemini가 실제로 읽은 자료 ID와 끝 표식을 확인한 후 같은 채팅에서 음성대화를 시작하세요. 페이지를 게시해도 Gemini의 전체 읽기나 음성대화 중 문맥 유지를 보장하지 않습니다. 공개 자료 수정·비공개 인박스 저장은 Gemini가 직접 할 수 없습니다.
