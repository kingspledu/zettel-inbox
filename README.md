# 모음 — 제텔카스텐 인박스

텍스트·링크·파일을 원문 그대로 수집하고 LLM 전달용 JSON으로 내보내는 서버 없는 웹앱입니다. GitHub Pages에서 실행합니다.

## 사용

내용, 출처 또는 파일을 입력하고 저장합니다. 검색과 선택 후 전체 또는 선택 JSON을 다운로드합니다. 내보낸 JSON에는 원문과 base64 첨부, 텍스트 파일의 UTF-8 해석본, LLM 명령 대기 지침과 최소 의미 단위 분리 절차가 포함됩니다. JSON 가져오기는 이 앱의 백업만 지원하고 같은 ID는 건너뜁니다. 일반 JSON은 파일 첨부로 수집하세요.

## 저장과 제한

수집 데이터는 IndexedDB를 통해 현재 브라우저·현재 사이트 주소에 저장됩니다. 서버 전송, LLM API 호출, 자동 분류, OCR, 음성 처리는 없습니다. LLM 음성대화는 다운로드한 JSON을 별도 서비스에 전달하여 수행합니다. PDF·이미지·오디오 등은 첨부 원본만 보관합니다. 텍스트 파일은 UTF-8을 가정합니다. 한 번의 첨부 합계는 25MB로 제한하며 실제 총 저장량은 브라우저 한도에 따릅니다. 브라우저 데이터 삭제·기기 변경 전에 JSON 백업이 필요합니다. JSON에는 첨부 원본까지 포함되므로 파일이 커질 수 있고 LLM의 업로드 한도와 형식 지원 여부를 확인해야 합니다. JSON 지침은 LLM의 준수를 보장하지 않습니다.

앱 코드는 공개 저장소와 Pages에 게시되며 사용자가 수집한 개인 자료는 GitHub에 올라가지 않습니다. 공개 코드에 민감 자료를 직접 추가하지 마세요.

## 개발

별도 빌드와 외부 의존성이 없습니다. `python -m http.server 8000`으로 실행하고 http://localhost:8000 에 접속합니다. `node test.cjs`로 내보내기·복원 형식과 지침을 검증합니다. main 브랜치 push 시 GitHub Actions가 Pages에 배포합니다.
