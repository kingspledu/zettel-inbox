# 모음 — 제텔카스텐 인박스

텍스트·링크·파일을 원문 그대로 수집하고 LLM 전달용 JSON으로 내보내는 웹앱입니다. GitHub Pages에서 실행합니다. 브라우저 저장 및 Firebase + 비공개 GitHub 연결을 지원합니다. **프로젝트 연결 전에는 브라우저 저장 모드입니다.** [클라우드 연결 안내](CLOUD_SETUP.md)를 참고하세요.

## 사용

내용, 출처 또는 파일을 입력하고 저장합니다. 검색과 선택 후 전체 또는 선택 JSON을 다운로드합니다. 내보낸 JSON에는 원문과 base64 첨부, 텍스트 파일의 UTF-8 해석본, LLM 명령 대기 지침과 최소 의미 단위 분리 절차가 포함됩니다. JSON 가져오기는 이 앱의 백업만 지원하고 같은 ID는 건너뜁니다. 일반 JSON은 파일 첨부로 수집하세요.

## 저장과 제한

기본 저장 모드에서는 IndexedDB를 통해 현재 브라우저·현재 사이트 주소에 저장합니다. 클라우드에 연결하면 Firebase에 텍스트와 메타데이터를, 별도 비공개 GitHub에 첨부 원본을 저장합니다. LLM API 호출, 자동 분류, OCR, 음성 처리는 없습니다. LLM 음성대화는 다운로드한 JSON을 별도 서비스에 전달하여 수행합니다. PDF·이미지·오디오 등은 첨부 원본만 보관합니다. 텍스트 파일은 UTF-8을 가정합니다. 한 번의 첨부 합계는 25MB, 클라우드 DB 본문은 약 800KB로 제한합니다. JSON 백업이 필요합니다. JSON에는 첨부 원본까지 포함되므로 파일이 커질 수 있고 LLM의 업로드 한도와 형식 지원 여부를 확인해야 합니다. JSON 지침은 LLM의 준수를 보장하지 않습니다.

앱 코드는 공개 저장소와 Pages에 게시됩니다. 클라우드 첨부는 별도 비공개 저장소에 올라갑니다. 토큰과 로그인 세션은 탭 메모리에만 유지합니다. 클라우드 삭제는 DB 항목만 삭제하며 GitHub 원본과 과거 이력은 남습니다. 공개 코드에 민감 자료를 직접 추가하지 마세요.

## 개발

별도 빌드는 없습니다. 클라우드 연결 시 Firebase SDK를 Google CDN에서 불러옵니다. `python -m http.server 8000`으로 실행하고 http://localhost:8000 에 접속합니다. `node test.cjs`와 `node cloud.test.cjs`로 내보내기·복원과 모의 API 기반 저장 분리를 검증합니다. 실제 Firebase 접근 규칙과 계정 연결은 별도로 검증해야 합니다. main 브랜치 push 시 GitHub Actions가 Pages에 배포합니다.
